# Words you can work with

A small starting vocabulary. Each chapter will give these words more texture and examples.

| Word | A useful working meaning |
| --- | --- |
| Persuasion | Communication intended to influence how someone understands or acts on a choice. |
| Framing | Presenting a subject so that particular aspects become prominent. |
| Archetype | A recurring story pattern used to organize meaning. |
| Positioning | The place you want a brand to occupy in an audience's understanding, relative to alternatives. |
| Hierarchy | The visual relationships that indicate importance and reading order. |
| Grid | A shared structure for aligning and relating elements. |
| Brand voice | Consistent choices in how a brand speaks. |
| Design token | A named, reusable style value, such as a color or spacing size. |
| Hero | A prominent opening area that introduces a page's main message. |
| Call to action | An invitation to take a particular next step. |
| Semantic HTML | Markup chosen for the meaning and role of content. |
| Selector | A pattern used to identify elements for styling or scripting. |
| Box model | The relationship between an element's content, padding, border, and margin. |

These are brief editorial definitions, not quotations. The [source shelf](sources.md) provides starting points for the underlying frameworks and technical terms.
