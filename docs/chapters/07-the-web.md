# From a story to a screen

> Chapter outline · ready to develop.

A poster can ask you to look. A web page can also ask you to do something. That changes the design problem: a beautiful invitation still needs a destination, readable information, and a way to act.

## The chapter ahead

- Web presence: how people discover a brand and what they need next.
- Hero, navigation, call to action, product details, FAQ, and footer.
- HTML for meaning, CSS for presentation, and JavaScript for behavior.
- Selectors and the box model as ways to understand what the browser builds.
- Clear content for people, assistive technology, search, and AI systems.

## Begin with the material

[MDN's semantic HTML curriculum](https://developer.mozilla.org/en-US/curriculum/core/semantic-html/) and [W3C's page structure tutorial](https://www.w3.org/WAI/tutorials/page-structure/) provide technical starting points. This chapter will connect their vocabulary to the brand decisions already made.
