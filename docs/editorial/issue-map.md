# Production issue map

Parent: [#73](https://github.com/kaw393939/is_117_white_t-shirt/issues/73). All entries below are planned work, not completed deliverables. This file is a creation-time map; GitHub is authoritative for current status.

## How to start

Resolve #98 (URL map), #99 (continuity) and #100 (registers) first. Research dossiers can then proceed independently. Produce #139, a finished sample sequence, early; its findings calibrate the rest of the manuscript. Chapter drafts integrate approved research and assets. Store construction proceeds #128 → #129 → #130 → #131 → #132, with #133 branching from #128. Testing and specialist review precede the final proof and #71 release gate.
