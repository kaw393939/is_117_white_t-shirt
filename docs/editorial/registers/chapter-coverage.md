## Metadata to record when a source is inspected

Each inspected record must include source ID; exact supported claim; creator/title/date/edition; heading, page or artifact locator; stable URL; source type; check date; status; rights/reuse limits; and unresolved questions. Record quote text and locator only if quoting is necessary. A research-family row cannot replace a claim-level citation in finished prose.

The brand dossier under #101 supplies its own BS-series source ledger. Other dossiers should use distinct prefixes and link back here. Do not overwrite the meaning of an existing ID. Asset files and licenses remain pending until their owner issues produce them; assigning an owner is not rights clearance.
