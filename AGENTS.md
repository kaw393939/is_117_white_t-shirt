# Working on this book

- Build a lively, readable book about the author's framework, not a course-management system.
- Stay within the requested chapter or change. Do not expand outlines into a full manuscript without being asked.
- Keep all book content in Markdown under `docs/`.
- Use the plain white T-shirt as a recurring thought experiment. Clearly label invented examples.
- Teach vocabulary through examples, comparisons, and deliberate revisions.
- Favor original research, the theorist's own work, historical documents, actual collection records, and official technical documentation. Museum essays are useful secondary interpretation; label them accurately.
- Verify facts, quotations, objects, and links. Never invent evidence or customer testimonials.
- Keep persuasion ethical, archetypes flexible, and design history more nuanced than simple style labels.
- Treat AI as a production tool directed by human intent and judgment. Preserve what the author says should stay unchanged.
- Do not add rubrics, grades, classroom administration, assignments, or student tracking unless explicitly requested.
- Keep the publishing setup small: Markdown, Jekyll, CSS, GitHub Actions, and GitHub Pages.
